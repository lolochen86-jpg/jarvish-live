# 實機驗收清單（尚未執行）

使用你自己的安全帽與已合法簽署的 App。此清單不含私人設備紀錄。

1. 在 iPhone 設定手動連上安全帽 Wi-Fi；回 App 讀取介面 IP／遮罩。比較設定畫面的手機 IP，不把它當成安全帽 IP。
2. 即使 router 空白、沒有網際網路，也嘗試 Bonjour 探索；記下當次時間、畫面及日誌。
3. 首次探索允許區域網路權限；若 15 秒已過，再按一次。確認拒絕後會留下錯誤／不確定結果，不會虛報設備離線。
4. 在設定重新開啟權限再測。模擬器無法代表這個權限流程。
5. 發現服務時核對名稱、類型、主機、IP、port。確認是你的設備，再以廠商文件或實際證據判定相機入口；Bonjour 類型本身不證明可播放。
6. 沒結果時保存日誌，記為「候選類型未發現」，不要填入猜測的設備 IP／串流網址。
7. 開始探索後停止、再開始、退到背景、返回，確認不混入前一次已取消的解析結果。更換 Wi-Fi 後重新探索。
8. 匯出 JSON，檢查時間／錯誤與畫面一致；分享前檢查 IP 和設備名稱。關閉再開不保證保留舊日誌。

完整驗收仍需：實體 iPhone 版本、有效簽署／安裝、區域網路權限、真實安全帽探索、已證明的相機服務；本版未實作串流播放器。
